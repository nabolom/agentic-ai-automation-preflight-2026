# Alcance de esta plantilla

Esta plantilla enseña un primer flujo de trabajo con GitHub y un diagnóstico offline. Al crear tu repo propio, tú decides qué notas y evidencias conservar.

La plantilla no es una sesión técnica ni un agente completo. Su propósito es llegar a la siguiente actividad con una identidad de GitHub, un repo propio, un commit de práctica o de cierre visible, un reporte de preflight y una intención inicial.
