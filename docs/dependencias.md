# Dependencias del preflight

| Elemento | ¿Es necesario? | Para qué sirve |
|---|---|---|
| Python 3.9+ | Sí | Ejecutar el diagnóstico offline |
| Git | Opcional | Clonar o actualizar repositorios |
| Claude Code | Opcional | Solo si ya lo usas; no se instala para este diagnóstico |
| Node/NPM | No requerido | No se usa en el preflight |
| API key | No requerida | El diagnóstico no llama a ningún modelo |
| Internet | No requerida | Todo lo necesario está en esta carpeta |

No instales herramientas por anticipado si no sabes qué problema resuelven. Si Python no está disponible, usa el fallback documentado y pide apoyo.
