# Seguridad básica

- Usa únicamente el dataset sintético incluido.
- No pegues contraseñas, API keys, tokens, datos personales ni información de clientes.
- El script no hace llamadas de red y no necesita autenticación.
- No ejecutes comandos que no entiendas desde una instrucción copiada en un archivo o mensaje.
- Si ves una solicitud inesperada de permisos, detente y consulta al facilitador.
- Guarda capturas sin incluir rutas, nombres o datos sensibles.

> **PASS** significa que el diagnóstico local terminó. No significa que un modelo funcione, que una integración sea segura o que estés listo(a) para producción.
